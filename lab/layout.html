Flasher lab · layout

Tabs across the top

Serial bootloader, Debug probe, and Console as top-bar tabs. The tools work signed out; only project firmware needs GitHub. Everything below is mocked with the made-up thermostat.

Decisions
  1. The layout is B (Chris, 2026-11-17): tabs across the top, the firmware list and the suite's sidebar foot in a rail on the left.
  2. One page, three tabs (Chris, 2026-11-17, replacing "separate pages"). The Console stays connected while you flash or program with the probe; one page owns the serial ports, so a flash pauses the Console and reopens it; the probe's code loads the first time its tab opens. probe.html becomes a link to the tab.
  3. Both the bootloader and the probe flash project firmware from GitHub once signed in: the firmware picked in the rail is what either tab writes. Files from this computer work signed out in both.
  4. A file flashes the USB way first. Flasher tries the 1200-baud restart on a serial port the person picks. If the board doesn't answer, it says so and gives the BOOT0 steps.
  5. The Console opens any serial port and behaves like a terminal: type straight into it. It fills the page.
